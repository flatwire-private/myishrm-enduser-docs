# Document Requests

Request official academic documents through MyISHRM.

---

## Overview

Students can request various official documents through the portal. The Registrar processes these requests and notifies you when ready for pickup.

---

## Available Documents

| Document | Description | Typical Fee |
|----------|-------------|-------------|
| **Transcript of Records (TOR)** | Official academic record | ₱100-200 |
| **Certificate of Enrollment (COE)** | Proof of current enrollment | ₱50-100 |
| **Certificate of Grades (COG)** | Grade certification | ₱50-100 |
| **Certificate of Graduation** | For graduates only | ₱100-150 |
| **Good Moral Certificate** | Character certification | ₱50-100 |
| **Certification/Authentication** | Verified copies | Varies |

*Note: Fees may vary. Check current rates with the Registrar.*

---

## How to Request a Document

### Step 1: Submit Request

1. Login to your student portal
2. Click **"Documents"** in the menu
3. Click **"Request Document"**
4. Select document type
5. Fill in:
   - Purpose of request
   - Number of copies
   - Additional notes (if any)
6. Click **"Submit Request"**

### Step 2: Pay Document Fee

- You'll be notified of the fee amount
- Pay at the Cashier's Office
- Keep your receipt

### Step 3: Wait for Processing

| Document | Processing Time |
|----------|-----------------|
| COE | 1-2 days |
| COG | 1-2 days |
| TOR | 3-5 days |
| Good Moral | 2-3 days |
| Others | Varies |

### Step 4: Pickup

- You'll receive a notification when ready
- Bring valid ID to claim
- Pickup at the Registrar's Office

## Request Status

| Status | Meaning |
|--------|---------|
| **Pending** | Request submitted, awaiting processing |
| **Processing** | Being prepared by Registrar |
| **Ready** | Ready for pickup! |
| **Released** | Already claimed |
| **Unpaid** | Fee not yet paid |
| **Rejected** | Request denied by Registrar (see reason) |
| **Cancelled** | Request cancelled |

## Tracking Your Requests

1. Go to **"Documents"** in the menu
2. View **"My Requests"** tab
3. See status of all your requests
4. Click on a request for details

---

## Tips for Document Requests

**Before Requesting:**
- Check if you have clearance (no holds on your account)
- Clear any outstanding balances
- Know the exact purpose (some documents require specific wording)

**For TOR Requests:**
- TOR is usually requested for:
  - Job applications
  - Graduate school applications
  - Transfer to another school
- Specify number of copies needed

**For Employment:**
- Request COE for proof of enrollment
- Request TOR for academic records
- Allow extra time for processing

---

## Special Cases

### Rush Processing

- Contact the Registrar directly
- Rush fee may apply
- Not always available

### Documents for Abroad

- Inform Registrar during request
- May need authentication from DFA
- Additional fees and processing time

### Lost Documents

- If you lose a released document, file a new request
- Full fee applies for replacement

---

## Common Questions

**Q: Can I request documents online only?**
A: You submit the request online, but pickup is in person at the Registrar's Office.

**Q: What if I have an outstanding balance?**
A: Clear your balance first. Document requests may be held.

**Q: Can someone else pick up my document?**
A: Yes, with authorization letter and valid IDs of both parties.

**Q: How many copies can I request?**
A: Specify the number when requesting. Each copy has a fee.
