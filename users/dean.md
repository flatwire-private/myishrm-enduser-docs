# Dean Guide

**Role:** Dean
**Primary Responsibility:** Manage college courses, curriculum, and faculty assignments

---

## Overview

As a Dean, you can:
- Create and manage courses for your college
- Add subjects to course curriculum
- Create course sections
- Assign faculty to sections
- Set class schedules
- Monitor college performance

---

## Login

1. Go to [https://myishrm.flatwire.io](https://myishrm.flatwire.io)
2. Enter your dean credentials
3. You'll see the Dean Dashboard

---

## Dashboard Overview

Your dashboard shows:
- **College Overview** - Your college's programs and statistics
- **Total Students** - Students enrolled in your college
- **Active Sections** - Current semester sections
- **Faculty** - Faculty members under your college

---

## Key Tasks

### Manage Courses (Programs)

**View Courses:**
1. Click **"Courses"** in the menu
2. See all programs under your college
3. Each course shows:
   - Program code (e.g., BSHRM)
   - Program name
   - Number of subjects
   - Enrolled students

**Create New Course:**
1. Click **"Courses"** → **"Add Course"**
2. Fill in:
   - Course Code (e.g., BSHRM)
   - Course Name (e.g., BS Hotel and Restaurant Management)
   - Description
   - Duration (years)
3. Click **"Create Course"**

---

### Manage Subjects (Curriculum)

**View Subjects:**
1. Click on a course
2. Click **"Subjects"** tab
3. See all subjects in the curriculum

**Add Subject to Course:**
1. Go to Course → Subjects
2. Click **"Add Subject"**
3. Fill in:
   - Subject Code (e.g., HRM101)
   - Subject Name (e.g., Introduction to Hospitality)
   - Units (lecture + lab)
   - Year Level (when taken)
   - Semester (1st or 2nd)
   - Prerequisites (if any)
4. Click **"Add Subject"**

---

### Create Course Sections

**Sections** are class groups for a subject (e.g., HRM101-A, HRM101-B).

**Steps:**
1. Go to Course → Subjects
2. Click on a subject
3. Click **"Create Section"**
4. Fill in:
   - Section Name (e.g., A, B, C)
   - Maximum Capacity (e.g., 40 students)
   - Schedule (day, time, room)
5. Click **"Create Section"**

---

### Assign Faculty to Sections

**Steps:**
1. Go to a section
2. Click **"Assign Faculty"**
3. Search for faculty by name
4. Select the faculty member
5. Click **"Assign"**

**Result:**
- Faculty can now see this class in their portal
- Faculty can submit grades for this section

---

### Set Class Schedules

**For Each Section:**
1. Click on the section
2. Click **"Set Schedule"**
3. Configure:
   - Day(s) of the week
   - Start time
   - End time
   - Room/Venue
4. Click **"Save Schedule"**

**Schedule Conflict Check:**
- System automatically checks for conflicts
- Alerts if faculty or room is already booked

---

## Academic Setup Workflow

Follow this order when setting up a new semester:

1. **Create/Update Courses** (if new programs)
2. **Add Subjects** to curriculum
3. **Create Sections** for each subject
4. **Assign Faculty** to each section
5. **Set Schedules** for each section
6. **Open Enrollment** (coordinate with Registrar)

---

## Common Questions

**Q: Can I edit a subject after creating it?**
A: Yes, click on the subject and click "Edit".

**Q: How do I remove a faculty from a section?**
A: Go to the section → Click "Change Faculty" → Select new faculty or remove.

**Q: What if there's a schedule conflict?**
A: The system will warn you. Adjust the time or room.

**Q: Can I see grades for my college?**
A: Yes, view grade reports under your dashboard.
