# Faculty Guide

**Role:** Faculty
**Primary Responsibility:** Submit student grades and manage classes

---

## Overview

As a faculty member, you can:
- View your assigned classes and schedule
- Submit student grades for each grading period
- Create and manage assignments
- Track student attendance
- Share resources with students
- View class rosters
- Communicate with students

---

## Login

1. Go to [https://myishrm.flatwire.io](https://myishrm.flatwire.io)
2. Enter your faculty email and password
3. You'll see your Faculty Dashboard

---

## Dashboard Overview

Your dashboard shows:
- **My Classes** - Classes assigned to you this semester
- **Pending Grades** - Classes awaiting grade submission
- **Grading Deadlines** - Important dates to remember

---

## Key Tasks

### View Assigned Classes

**Steps:**
1. Click **"My Classes"** in the menu
2. See all classes assigned to you
3. Each class shows:
   - Subject name and code
   - Section
   - Schedule
   - Number of students

---

### Submit Grades

This is your primary task each grading period.

**Grading Periods:**
1. **Prelims** - First quarter grades
2. **Midterm** - Second quarter grades
3. **Finals** - Third quarter grades

**Steps to Submit Grades:**
1. Click **"Grades"** in the menu
2. Select a class
3. Click on the grading period (Prelims/Midterm/Finals)
4. Enter grades for each student
5. Click **"Save"** to save your progress
6. Click **"Submit"** when all grades are entered

**Grade Input:**
- Enter grades from 1.0 to 5.0
- Use INC for Incomplete
- Use DRP for Dropped students

**Grade Scale:**
| Grade | Description |
|-------|-------------|
| 1.0 | Excellent (97-100) |
| 1.25 | Very Good (94-96) |
| 1.5 | Very Good (91-93) |
| 1.75 | Very Good (88-90) |
| 2.0 | Good (85-87) |
| 2.25 | Good (82-84) |
| 2.5 | Good (79-81) |
| 2.75 | Satisfactory (76-78) |
| 3.0 | Satisfactory (75) |
| 5.0 | Failed (Below 75) |

---

### Grading Deadlines

**Important:** Submit grades before the deadline!

**How to Check Deadlines:**
1. View the deadline banner on your dashboard
2. Yellow warning = Deadline approaching
3. Red warning = Deadline today or overdue

**What Happens After Deadline:**
- Late submissions may require Registrar approval
- Contact Registrar if you need an extension

### View Class Roster

**Steps:**
1. Click **"My Classes"**
2. Select a class
3. Click **"View Roster"**
4. See list of all enrolled students with:
   - Student ID
   - Name
   - Email
   - Enrollment status

---

### Send Messages to Students

**Steps:**
1. Click **"Messages"** in the menu
2. Click **"New Message"**
3. Search for student by name or ID
4. Type your message
5. Click **"Send"**

---

### View Your Schedule

**Steps:**
1. Click **"Schedule"** in the menu
2. View your weekly teaching schedule
3. Each slot shows:
   - Subject name and code
   - Section
   - Day, time, and room

---

### Mark Attendance

**Steps:**
1. Click **"Attendance"** in the menu
2. Select a class
3. Select the date
4. Mark each student as:
   - **Present**
   - **Absent**
   - **Late**
   - **Excused**
5. Click **"Save Attendance"**

---

### Manage Assignments

For a complete guide see [Assignments](features/assignments.md).

**Create an Assignment:**
1. Click **"Assignments"** in the menu
2. Click **"Create Assignment"**
3. Fill in:
   - Title and description
   - Class (select from your assigned sections)
   - Type: **Assignment** (students submit work) or **Instruction** (announcement only)
   - Deadline date and time
   - Grace period (optional, in hours)
4. Attach files if needed (instructions, templates)
5. Click **"Save"** to keep as draft, or **"Publish"** to make visible to students

**Grade Submissions:**
1. Click **"Assignments"** → select an assignment
2. Click **"View Submissions"**
3. Click on a student's submission to open it
4. Review their uploaded files
5. Enter a grade and optional feedback
6. Click **"Save Grade"**

**Download All Submissions:**
- From the submissions list, click **"Download All"** to receive a ZIP file of every submission.

---

### Share Resources

**Steps:**
1. Click **"Resources"** in the menu
2. Click **"Upload Resource"**
3. Select the class this resource is for
4. Upload the file and add a title/description
5. Click **"Save"**

Students in that class can then view and download the resource from their portal.

## Common Questions

**Q: Can I edit grades after submitting?**
A: Once submitted, grades are locked. Contact the Registrar to request changes.

**Q: What if I miss the deadline?**
A: Contact the Registrar immediately. They may grant an extension.

**Q: How do I mark a student as dropped?**
A: Use "DRP" as the grade for officially dropped students.

**Q: What is an incomplete (INC) grade?**
A: INC is given when a student has pending requirements. Must be completed within the specified period.
