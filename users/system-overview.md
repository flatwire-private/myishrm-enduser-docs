# System Overview

Welcome to MyISHRM - the Student Information System for ISHRM (International School of Hospitality and Restaurant Management).

---

## What is MyISHRM?

MyISHRM is an online portal that helps students, faculty, and staff manage academic activities including:

- Student enrollment and registration
- Grade viewing and submission
- Payment tracking
- Document requests
- Class schedules
- Internal messaging

---

## Who Uses MyISHRM?

| Role | What They Do |
|------|-------------|
| **Applicant** | Apply for admission, upload documents, pay fees |
| **Student** | View grades, schedules, pay tuition, request documents |
| **Faculty** | Submit grades, view class rosters |
| **Dean** | Manage courses, assign faculty to sections |
| **Admission Officer** | Review applications, approve and generate invoices |
| **Registrar** | Convert applicants to students, manage enrollments |
| **Accounting Staff** | Verify payments, manage student accounts |
| **Admin** | Manage users, configure system settings |

---

## Key Features

### For Applicants
- Online application submission
- Document upload
- View admission invoice
- Upload payment proof
- Track application status

### For Students
- View class schedule
- Check grades (Prelims, Midterm, Finals)
- View payment history
- Request official documents (TOR, certificates)
- Send messages to faculty/staff

### For Faculty
- View assigned classes
- Submit student grades
- View class rosters
- Communicate with students

### For Staff
- Process applications and enrollments
- Verify payments
- Generate documents
- Manage student records
